# タスク：タスクのインライン編集中に「十分なアクセスがありません」というメッセージが表示される

>[!NOTE]
>
>この問題は、2025年11月21日（PT）に修正されました。

ユーザーがリストまたはレポート内でタスクをインライン編集しようとすると、タスクを編集できず、「このタスクに対して割り当てを行う十分なアクセス権限がありません」というメッセージが表示されます。

この問題は、ユーザーがタスクに対する権限を継承し、プロジェクト共有で「割り当てを行う」オプションが無効になっている場合に発生します。

**回避策**

タスクを開いて直接編集します。

_最初に報告されたのは、2025年11月10日（PT）です。_
